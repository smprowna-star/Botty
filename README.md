# Discord Bot for Render

Prefix: ¥

Features:
- Games system
- Moderation commands
- Voice/music queue commands
- Render web server
- Slash command sync

Render Build Command:
pip install -r requirements.txt

Render Start Command:
python main.py

Environment Variable:
DISCORD_TOKEN = your Discord bot token

IMPORTANT:
The current music commands provide voice connection and a queue, but they do not download or stream audio from external music services.
Keep your Discord bot token private.
